Recommendations

Proposed Design Improvements

Evidence-based recommendations derived from heuristic evaluation and SUS usability testing to improve the CommonWell Healthcare Management System.

Design Recommendations

Improvement Proposals

Prioritized by severity and implementation feasibility
01
H4 — Consistency · High Priority

Establish a Unified Design System

Create and enforce a consistent component library across all modules — appointment booking, health records, medication tracking, vaccination tracker, and the admin panel. Standardize button styles, colors, typography, spacing, and interactive states. Consider implementing a shared CSS stylesheet or design token system (e.g., CSS variables) to ensure visual consistency. Users should not need to relearn UI patterns when switching between modules.

02
H10 — Help & Documentation · High Priority

Add Contextual Help & Onboarding

Introduce an onboarding walkthrough for first-time users that highlights key features and navigation flows. Add tooltips on complex form fields (e.g., medical record inputs) and an accessible FAQ or help center within the platform. Given that the primary audience includes community members unfamiliar with health technology platforms, in-context guidance is essential to reducing friction and abandonment rates.

03
H9 — Error Recovery · High Priority

Improve Error Messages & Recovery Paths

Rewrite all system error messages to be specific, plain-language, and action-oriented. Each error should: (1) clearly describe what went wrong, (2) explain why it happened if helpful, and (3) offer a concrete next step. For form validation errors, highlight the specific field and provide inline guidance. Replace generic "Something went wrong" messages with targeted feedback such as "Please enter a valid date of birth in MM/DD/YYYY format."

04
H3 — User Control · Medium Priority

Implement Clear Navigation Controls in Multi-Step Flows

Add explicit "Back," "Cancel," and "Save Draft" options throughout the appointment booking and form submission flows. Users should always feel in control and confident that abandoning a flow will not result in lost data. Consider a progress indicator (e.g., Step 1 of 3) to set expectations and reduce anxiety during longer task sequences.

05
H1 — Visibility · Medium Priority

Provide Consistent System Feedback

Add loading indicators, success confirmations, and status messages for all user-initiated actions. After submitting an appointment, saving a health record, or updating medication information, the system should immediately confirm success (e.g., a toast notification: "Appointment booked successfully for May 10, 2025"). This addresses user uncertainty and builds trust in the platform's reliability.

06
H5 — Error Prevention · Medium Priority

Add Confirmation Dialogs for Irreversible Actions

Before users can delete records, cancel appointments, or perform other irreversible actions, present a confirmation dialog that clearly states the consequence. For example: "Are you sure you want to cancel this appointment? This action cannot be undone." This prevents accidental data loss and reduces the cognitive burden of needing to remember which actions are reversible.

07
H7 — Flexibility · Low Priority

Introduce Shortcuts for Power Users

For admin users and frequent platform users, add keyboard shortcuts, quick-action menus, and saved filters or templates for common workflows. Admin staff managing multiple patient records daily will benefit significantly from features like bulk actions, search shortcuts, and pre-filled appointment templates based on past visits. This maintains accessibility for new users while improving efficiency for experienced ones.

Design Vision

Suggested Interface Improvements

Visual and structural changes proposed for the next iteration
🎨

Unified Color System

Define a primary teal palette with semantic color usage — success (green), warning (amber), danger (red) — applied consistently across all modules and alerts.

📋

Streamlined Appointment Flow

Redesign the booking experience as a 3-step wizard with a visible progress bar: (1) Select Service → (2) Choose Date/Time → (3) Confirm Details.

📊

Patient Dashboard Redesign

Create a personalized dashboard that surfaces upcoming appointments, recent health records, and pending vaccinations in a single glanceable view using card-based layout.

📱

Mobile-First Responsive Design

Optimize all pages for smartphone use, as many community members will access the platform via mobile. Prioritize touch targets, thumb-friendly navigation, and readable typography at small sizes.

🔔

Notification System

Implement in-app and email notifications for appointment reminders, vaccination schedule alerts, and medication refill prompts to keep patients proactively engaged.

♿

Accessibility Improvements

Ensure WCAG 2.1 AA compliance: sufficient color contrast ratios, ARIA labels on interactive elements, keyboard-navigable UI, and screen reader-compatible markup throughout.

Conclusion

Summary

The CommonWell Healthcare Management System demonstrates strong potential as a community health platform. The core concept — providing Barangay Halawig-Gogon residents with digital access to appointment booking, health records, and vaccination tracking — addresses a genuine need, and the prototype reflects thoughtful initial design.

However, the usability evaluation revealed that several foundational HCI principles require attention before the system is ready for public deployment. The three high-severity issues — inconsistency (H4), error recovery (H9), and lack of help documentation (H10) — represent significant barriers to adoption, particularly for users with limited digital health experience.

By implementing the recommendations in this report, the CommonWell development team can significantly improve the system's usability, accessibility, and user confidence — moving the platform closer to an excellent SUS score and ensuring it genuinely serves its target community.
