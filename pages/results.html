Key Issues Identified

Usability Issues Found

Consolidated from heuristic evaluation and usability testing
High Severity H4 — Consistency

Inconsistent UI Components Across Modules

Button styles, colors, and interactive element behaviors vary significantly between the appointment booking, health records, and admin panel modules, creating confusion for users navigating between sections.

High Severity H10 — Help

Absence of In-App Help and Documentation

Users have no access to tooltips, tutorials, or contextual help within the system. First-time users — especially community members unfamiliar with digital health platforms — are left without guidance.

Medium Severity H3 — User Control

No Clear Navigation Back From Booking Flow

Once users enter the appointment booking sequence, there is no obvious way to cancel or go back without losing entered data, reducing users' sense of control over the system.

Medium Severity H1 — Visibility

Missing Feedback After User Actions

After submitting forms or completing actions, the system does not consistently provide confirmation messages or loading indicators, leaving users uncertain whether their action was successful.

Low Severity H7 — Flexibility

No Keyboard Shortcuts or Power-User Features

Experienced users or admin personnel have no efficiency shortcuts, forcing them to navigate the same steps as first-time users regardless of familiarity with the system.

Discussion

Discussion of Findings

The usability evaluation of the CommonWell Healthcare Management System revealed that while the platform demonstrates a clean, aesthetically minimalist design (H8 — passed), significant usability gaps exist in the areas of consistency, error handling, and user guidance. These issues are particularly critical given the platform's intended audience: community members of Barangay Halawig-Gogon, many of whom may have limited experience with digital health systems.

The SUS testing results indicate that respondents generally found the core functionality accessible, but struggled with the absence of clear feedback mechanisms and the inconsistency of UI components across modules. The three high-severity heuristic violations — consistency (H4), error recovery (H9), and help documentation (H10) — collectively degrade the user experience, particularly for users attempting to complete multi-step tasks such as appointment booking.

The vaccination tracker and health records modules performed relatively better in testing, as they presented information in a straightforward list format that aligns with users' mental models. The admin panel, however, exhibited the most complexity and would benefit most from additional documentation and interface consistency improvements.
